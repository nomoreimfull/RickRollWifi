<H2>SSID RICK ROLL... Now with a hit counter! COUNTER</H2>

<img width="428" height="319" alt="nggyu" src="https://github.com/user-attachments/assets/efde57eb-df42-40fc-8c2d-974ea5803044" />


This project is a Rick Roll SSID prank. Designed for the ESP8266. The original project sequentially steps through the lyrics of the song every 20000ms with the next line of the song. Where lyrics exceed 32 chars, they have been broken into two parts. This new version includes animation and a persistent score counter. Target display is a SSD1306 128*32 I2C OLED.  

The STL is a a TV style case and can house a D1 mini, ssd1306 128x64. To power I used a USB-C female breakout hotglued into the rear of the case.
