<H2>SSID RICK ROLL... Now with a hit counter!</H2>

<img width="428" height="319" alt="nggyu" src="https://github.com/user-attachments/assets/efde57eb-df42-40fc-8c2d-974ea5803044" />

This project is a Rick Roll SSID prank designed for the ESP8266. Every 20 seconds, the device changes its broadcast SSID to the next line of lyrics from the song, sequentially delivering the Rick Roll through nearby Wi-Fi network lists. Lyrics exceeding the 32-character SSID limit are divided into multiple parts. This updated version adds animation and a persistent score counter. Target display is a SSD1306 128*32 I2C OLED.  

The STL is a a TV style case and can house a D1 mini or smaller ESP.

<img width="415" height="331" alt="image" src="https://github.com/user-attachments/assets/ae1a3adc-8bae-4af4-a288-c698adc52adb" />
